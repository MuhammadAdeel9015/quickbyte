# QuickBite Admin Web Portal

This is a frontend-only admin portal demo. It uses plain HTML, CSS, and JavaScript with seeded sample data. Changes are saved in the current browser using `localStorage`; there is no backend, API, or server integration.

## Run the demo

Open `index.html` in a modern browser.

Demo sign-in:

- Email: `admin@quickbite.test`
- Password: `QuickBite123`

Use the browser's site-data controls to clear the demo data and restore the original sample records.
